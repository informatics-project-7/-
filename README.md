Для просмотра мероприятий я просто показываю всё, что есть в базе данных. А для добавления нового мероприятия я сначала проверяю, имеет ли человек права администратора. 5. Удаление последней заявки /cancelapp

Я не стала писать сложную логику удаления в этом файле, а просто позвала готовую функцию из другого файла и передал ей нужные данные. Это помогает держать этот файл простым и понятным, без длинных кусков с запросами к базе данных.
