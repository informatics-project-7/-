# Отзыв по проекту БЛС

## Мэри

**Что сделала:** полноценный код Telegram-бота (~250 строк) для школьного совета — регистрация, подача заявок в комитеты, управление событиями, база SQLite.

**Сильные стороны:**
- Реально работающий функционал с несколькими командами.
- Структурированный код с функциями работы с БД.
- Система ролей (администратор / участник), обработка ошибок, дружелюбный UI с эмодзи.

**Что можно улучшить:**
- Токен бота вынести в `.env` (переменные окружения).
- Комментарии к ключевым функциям помогут коллегам разобраться.
- Добавить функцию просмотра поданных заявок.
